# Maturitní kánon 17

Interaktivní myšlenkové mapy 17 děl z maturitní četby z češtiny. U každého díla jsou větve autor, zařazení, forma a žánr, doba, souvislosti, téma, motivy, časoprostor a postavy s krátkým popisem.

Celá stránka je jeden soubor `index.html` bez build kroku. Lokálně se dá otevřít přímo v prohlížeči.
